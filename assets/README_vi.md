# Ảnh minh hoạ cho extension có repo riêng tư

## Thư mục này dùng để làm gì
Một số extension của GP247 (template, plugin trả phí) có mã nguồn ở repo **riêng tư**. README của chúng vẫn được hiển thị công khai,
ví dụ trên trang sản phẩm ở gp247.net — nhưng ảnh nằm trong repo riêng tư thì người xem không tải được.
Vì vậy ảnh minh hoạ của các extension đó được đặt ở đây, và README của extension trỏ thẳng tới ảnh trong thư mục này.

Chỉ chứa **ảnh** (ảnh chụp màn hình trên dữ liệu mẫu, logo), không chứa mã nguồn hay tài liệu.

## Quy ước
| Mục | Quy ước |
| --- | --- |
| Đường dẫn | `assets/<TênRepo>/<tên-ảnh>` — `<TênRepo>` trùng tên repo của extension, ví dụ `assets/GP247MKP/home.jpg` |
| Link trong README | `https://raw.githubusercontent.com/gp247net/gp247-docs/main/assets/<TênRepo>/<tên-ảnh>` |
| Nội dung ảnh | Chỉ dữ liệu mẫu: không thông tin khách hàng, license, khoá, địa chỉ máy chủ thật |
| Đổi ảnh | Thay file ở đây cùng lúc với bản trong repo của extension, giữ nguyên tên file để link cũ vẫn chạy |
