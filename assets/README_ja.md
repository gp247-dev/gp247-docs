# 非公開リポジトリの拡張機能用の画像

## このフォルダーの目的
GP247 の一部の拡張機能（テンプレート、有料プラグイン）は、ソースコードを**非公開**リポジトリで管理しています。README は gp247.net の
商品ページなどで公開表示されますが、非公開リポジトリ内の画像は閲覧者が読み込めません。
そのため、これらの拡張機能の画像はここに置き、拡張機能の README からこのフォルダーの画像を直接参照します。

このフォルダーには**画像のみ**（サンプルデータで撮影した画面、ロゴ）を置き、ソースコードやドキュメントは置きません。

## ルール
| 項目 | ルール |
| --- | --- |
| パス | `assets/<リポジトリ名>/<画像名>` — `<リポジトリ名>` は拡張機能のリポジトリ名（例：`assets/GP247MKP/home.jpg`） |
| README でのリンク | `https://raw.githubusercontent.com/gp247net/gp247-docs/main/assets/<リポジトリ名>/<画像名>` |
| 画像の内容 | サンプルデータのみ。顧客情報、ライセンス、キー、実際のサーバーアドレスは含めない |
| 画像の差し替え | 拡張機能のリポジトリ内のコピーと同時にここのファイルも差し替え、既存のリンクが切れないようファイル名は変えない |
